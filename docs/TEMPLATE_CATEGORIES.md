# 模板分类说明 | Template Categories

- [`undergraduate-thesis-generic`](../templates/undergraduate-thesis-generic/)：本科论文通用骨架
- [`thesis-proposal`](../templates/thesis-proposal/)：开题报告通用骨架
- [`defense-slides`](../templates/defense-slides/)：16:9 答辩幻灯片

## 课程作业

- [`engineering-report`](../templates/engineering-report/)：课程报告
- [`lab-report`](../templates/lab-report/)：实验报告

## 竞赛

- [`competition-paper`](../templates/competition-paper/)：学科竞赛技术论文

简历和项目申请书尚未提供。新增模板时要在目录中登记，并附虚构示例、README 和可重复的 XeLaTeX 构建。
